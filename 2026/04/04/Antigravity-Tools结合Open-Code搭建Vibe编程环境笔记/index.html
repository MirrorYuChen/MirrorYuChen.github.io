Antigravity Tools结合Open Code搭建Vibe编程环境笔记

发表于 2026-04-04 更新于 2026-07-09 分类于 tools
Antigravity Tools结合Open Code搭建Vibe编程环境笔记，包含Antigravity Tools安装、Open Code安装及如何串联；

1.Antigravity Tools安装

卖家会提供：账号|密码|2FA密钥

  • (1) 下载地址：Antigravity-Manager
  • (2) 下载文件：Antigravity.Tools_4.1.29_x64-setup.exe
  • (3) 双击安装后，使用OAuth授权添加账号

  • (4) 输入账号密码后，认证方式选择从Google身份验证器应用获取验证码

  • (5) 使用2FA生成密钥填入

2.安装Open Code

  • (1) OpenCode 安装：opencode
  • (2) 对于windows，直接下载exe双击安装即可。

3.Antigravity Tools代理到Open Code

  • (1) API代理 -> Cli 配置一键同步 -> “OpenCode配置” -> “立即同步配置”即可。

  • (2) 生成配置文件路径为：~/.config/opencode/opencode.json

4.Docker容器中搭建OpenCode

  • (1) 安装nodejs
  • (2) 安装opencode
  • (3) 配置api代理
  • (4) 使用vibe
