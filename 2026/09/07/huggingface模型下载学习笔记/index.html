3.2 命令和参数讲解

 基础命令格式：

 参数说明：

参数 说明 默认值 示例
REPO_ID (必需) 仓库ID，格式为 用户名/仓库名。 无 meta-llama/Llama-3.2-1B-Instruct
[FILENAMES] (可选) 指定要下载的单个或多个文件名。 下载整个仓库 config.json tokenizer.json
--repo-type 仓库类型。 model --repo-type dataset
--revision 指定分支、标签或提交哈希。 默认主分支 --revision v1.1
--include 包含匹配的文件 (支持通配符)。 无 --include "*.safetensors"
--exclude 排除匹配的文件 (支持通配符)。 无 --exclude "*.bin"
--local-dir 下载到指定目录，而非缓存文件夹。 无 --local-dir ./models/llama
--cache-dir 指定自定义缓存目录。 系统默认缓存路径 --cache-dir ./my_cache
--force-download 强制重新下载，即使文件已缓存。 no-force-download --force-download
--dry-run 模拟运行，仅显示会下载什么，不实际下载。 no-dry-run --dry-run
--token 用于身份验证的User Access Token。 使用已保存的token --token hf_***
--quiet 静默模式，不显示进度条，只输出最终路径。 no-quiet --quiet
--max-workers 并发下载的最大线程数。 8 --max-workers 16
-h, --help 显示帮助信息并退出。 - hf download -h
