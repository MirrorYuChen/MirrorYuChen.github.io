5.日常使用

  • （1）新建文章：hexo new "文章标题"，会在source/_posts下生成Markdown文件，编辑该文件即可写文章；
  • （2）更换主题：下载Hexo主题（如，Next、Butterfly），放在themes文件夹，修改_config.yml中的theme:主题名，重新部署即可；
  • （3）本地修改后，重新部署：重复执行hexo cl && hexo g && hexo d。
